# CO2 Emission Prediction Using Machine Learning

A final-year project that predicts CO2 emissions from vehicle engine parameters using machine learning regression models.

## Abstract
In developing countries, increasing carbon emissions are a major concern. This study evaluates CO2 emission levels using data mining techniques and builds a predictive model based on engine characteristics and fuel consumption data.

## Dataset
- **FuelConsumptionCo2.csv**: Contains engine size, fuel consumption, and CO2 emissions for various vehicle models.

## Model
- Linear regression model trained on engine size to predict CO2 emissions
- Pre-trained model saved as `model.pkl`

## How to Run
```bash
pip install flask numpy scikit-learn
python main.py
```
Then open http://127.0.0.1:5000 in your browser.
